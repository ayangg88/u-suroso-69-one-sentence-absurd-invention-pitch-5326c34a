## The pitch

> The Comfort Charger is a phone charger that unplugs itself the moment you finally get comfortable, then plays a tiny violin to mark the occasion.

One sentence, 145 characters. A ridiculous invention for a tiny everyday annoyance: the charger that quits the second you settle in — and rubs it in with a tiny violin.

## How it works

`main.py` writes the pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), with no trailing newline. It asserts the bounty gate first — one sentence, 1–220 characters — and reads the file back to confirm it holds exactly the pitch. Deterministic: no input, no randomness.

```sh
python3 main.py
```
